# 中继网页管理后台实施与验证

日期：2026-09-14。此记录补充 [引导与中继实施记录](RELAY_SETUP_2026-09-14.md)，后台相关现状以本文件和 [使用指南](../user/SELF_HOSTED_RELAY.md) 为准。

## 已实现

- 随中继服务部署的 `/admin/` 网页后台，无独立前端服务或外部 CDN；沿用客户端 C1 品牌图标。
- 中文/英文切换，桌面与窄屏布局，总览、游戏设备、客户端授权、连接指南。
- 管理密码登录；密码未配置时关闭管理接口。部署时设置强密码与服务公开地址，无匿名抢占式初始化。
- 游戏设备添加、凭据一次显示与复制、重命名、在线状态、邀请生成及整个设备撤销。
- 已配对客户端列表、所属设备、在线连接与单独撤销；撤销前确认影响范围，保留已撤销记录供查询。
- 自动/手动刷新、搜索、空列表、离线状态、失败提示、过期邀请提示，以及模态窗口关闭后的敏感文本清理。
- 原插件内邀请功能、桌面邀请格式和中继协议版本保持兼容。

## 修复的启动问题

开发过程中出现一次 `dotnet.exe` 的 `0xe0434352` 弹窗。复现捕获到的根因是通过 `WebApplicationBuilder.WebHost.UseWebRoot` 在创建构建器后更改网页根目录，触发 `NotSupportedException`。现改为在 `WebApplicationOptions` 中设置网页根目录。额外修复 `/admin` 与 `/admin/` 重复路由，并使用普通控制台日志避免受限 Windows 账户的 Event Log 写权限错误。

服务启动异常现输出明确错误并以退出码 1 结束，不再让配置错误变成未处理异常。修复后的普通启动和发布目录启动均已验证；错误密码配置也已验证为受控退出。该问题发生于新后台预览启动阶段。
