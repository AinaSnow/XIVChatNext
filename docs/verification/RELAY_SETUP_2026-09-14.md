## 验证中修正

- Windows Schannel 证书导入使用临时用户密钥容器，Linux 使用临时密钥集；不持久保存明文证书私钥。
- 修正端点数据帧组装计数，避免把流消费者的小块读取误算为过大报文。
- 控制注册/会话就绪顺序、旧会话退出及发送器销毁按会话生命周期收束。
- HTTP 响应体和部分控制帧增加独立超时，防止只收到响应头或部分数据后无限等待。
- 引导和配对窗口使用随主题变化的明确背景；引导状态提示固定在底部，通知页无需滚动才能看到测试反馈。
- 初次失败的中继连接不自动重试；已成功会话异常结束才进入自动恢复，显式断开取消延迟重试。
- 邀请确认绑定当前已查看的完整输入；延迟的输入变更事件不应清除相同邀请的确认，实际修改后则必须重新核对。相同名称的中继配置按稳定 ID 区分，避免编辑/删除混淆目标。
- 插件设置保存失败回滚地址和凭据；已运行的中继实例固定使用建立连接时的地址，避免尚未保存的配置变化影响邀请请求目标。
