# 第七阶段：多窗口、布局与历史导出

2026-09-12：实现、自动化联调及正常客户端离线操作验收完成。真实游戏在本轮后半程未运行，多窗口实际收发、退出与重连，以及前面阶段遗留的现场项目仍待补验；以下回环协议结果不等同于游戏实测。

## 已实现

- 会话和频道标题旁提供弹出按钮与拖动把手；同一连接、角色及视图最多一个小窗，重复打开会激活已有窗口。拖动把手在聊天内容区外释放时弹出，Escape 取消。
- 小窗共享应用连接、消息服务及会话已读状态；阅读旧消息时不提前清除新消息未读，阅读最新消息时参与通知抑制。通知点击优先定位已有的小窗。
- 小窗分别保存草稿、未完成发送、失败待恢复草稿、消息阅读锚点、尺寸、位置、置顶、字号、时间戳及 Markdown 设置。主窗口草稿与小窗互不覆盖；加载较旧布局也不回滚当前草稿。
- 私聊固定原始目标及角色，频道消息仍发送到游戏当前频道，并携带角色、登录轮次和频道修订校验。旧角色小窗保持原始归属并禁止发送，恢复原角色后重新绑定会话；迟到失败回执可以找到重新创建的小窗并恢复其草稿。
- 主窗口关闭且仍有小窗时隐藏主窗口并保留共享连接；“返回主窗口”复用原窗口。关闭最后一个聊天窗口时取消导出和截图、停止连接、保存草稿及布局、释放历史库，并关闭辅助窗口。主菜单“退出”关闭整个应用。
- 启动恢复上次布局，包括仅显示小窗的状态。布局窗口提供日常社交、副本交流、装修采购三种排列及自定义命名保存／加载。预设排列当前视图；没有小窗时弹出当前视图。
- 启动、显示器变化及 DPI 变化时，将普通状态窗口修正到最近显示器的可见工作区。损坏或未知版本布局保留原始数据，当前会话使用临时状态并提示错误。
- TXT 和真正的 Unicode RTF 从 SQLite 流式导出，不受界面当前加载数量限制。继承当前会话、频道、搜索、书签或收藏来源范围，允许调整关键词与起止日期时间；结束时间不包含在范围内。最多预览 100 条，预览只扫描最近 500 个数据库候选项。
- 导出明确标注本地数据库、原始角色和保存连接；历史关闭、已清理、未保存或原消息缺失时给出提示。使用 Windows 事务写入，成功时截去旧文件尾部，取消或失败不提交部分内容。

## 状态与边界

布局存于现有 SQLite `window_layouts` 表：`current` 为启动状态，命名布局独立保存。最多同时打开 12 个小窗、保留 64 个视图状态、保存 50 个命名布局。达到状态上限时只回收已关闭且没有普通／失败／待发送草稿的视图；不通过淘汰未发送内容腾空间。JSON 有大小、版本、身份、字段长度及重复视图校验。

小窗保留自己的来源连接与角色，不随当前登录切换目标。应用层仍只有一条活动游戏连接。历史锚点使用数据库稳定消息标识；原消息被清理或筛选排除时提示锚点不可用。延迟执行的旧消息定位带有代次保护，不能覆盖随后“返回最新”的滚动请求。

自动化使用独立数据库和回环服务，不读取或保存用户配置，不向游戏或其他玩家发送消息。回归结果和界面图在 `artifacts/phase7/`，不纳入 Git；复现命令见 [测试说明](../tests/README.md)。

正常客户端离线操作另外确认：按钮弹出、重复视图管理、本地历史与角色标识、拖动把手释放到标题栏后弹出、标题栏关闭小窗后主窗口保留、关闭主窗口后小窗保留、最后一个小窗关闭后进程退出，以及重启仅恢复小窗及未发送草稿。随后返回主窗口并移除本轮输入的临时草稿，保留正常主窗口供继续使用。桌面操作工具限制拖动终点必须位于目标窗口范围内，因此完整拖出原生窗口外的手势没有列为实测通过；释放到 XAML 内容区外的处理路径已验证。
