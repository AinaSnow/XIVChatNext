# 卡片文本与加载体验打磨

针对物品／装备卡片出现日文原始数据与中文文本无提示混排的问题，统一了字段回退、加载、刷新及展示行为。

## 本次行为

- 中文模式下，名称、分类、职业、说明、属性、装备、魔晶石、材料、商店及地名使用同一回退规则：有中文时显示中文，缺失时保留原文并附“暂无中文”。不会猜译名称，也不改变游戏提供的数值。旧格式属性文本没有独立翻译字段时同样明确标记。
- “游戏原文”切换整张卡片的游戏数据文字；界面按钮和说明继续使用客户端界面语言。中文数据来自独立服务，因此最新游戏版本中的部分内容仍可能没有中文。
- 初次加载中文时显示加载状态，标题和基本资料一起发布。装备、配方和来源先准备其中文名称，再发布该区域；切换语言时保留当前页面，待文字准备好后更新。加载期间禁用复制和收藏，避免保存中间状态。
- 同一卡片的异步更新合并到较少次数的 DOM 更新，不再反复导航整个 WebView 文档；保留阅读位置和“数据来源与版本”的展开状态。切换到另一件物品时回到顶部。
- 数据来源、游戏版本和中文数据版本收进可展开区域，仍可查看原始时间与来源。
- 刷新物品卡片会绕过中文物品资料及关联名称的有效期缓存，重新请求；请求失败保留已有可读缓存。普通打开仍复用七天内的缓存。
- 复制和从卡片收藏使用相同的显示名称与属性文本。再次收藏可更新显示名称，同时保留原有备注、分组、标签和原始消息归属。

## 验证

- 通用回归 56/56 组通过；新增检查覆盖关联名称主动刷新、普通打开命中缓存、刷新失败保留旧缓存。
- 卡片 WinUI／WebView 检查共 61 条通过（包含协议夹具响应校验）；新增覆盖中文请求延迟、日文缺失字段标记、中文属性数值、来源折叠、两类缓存刷新、复制、收藏更新与备注保留、DOM 文档复用、阅读位置及展开状态保持。
- 原有 HQ／收藏品／任务物品、装备比较、材料与地图跳转、分页、角色隔离、迟到响应和断线缓存检查通过。
- 独立夹具使用模拟中文 HTTP 响应及加密回环游戏协议，不连接真实游戏或改动用户收藏。界面预览已人工查看。结果及 PNG 在 `artifacts/card-polish/`，不纳入 Git。
- 正常桌面入口 Debug 构建通过；保留既有 Windows App SDK 发布配置告警。本轮不把真实在线中文服务的覆盖率或游戏现场操作计为实测通过。

测试入口仍为 `tests/DesktopCardsSmoke.targets`，构建方式见 [测试说明](../tests/README.md)。
