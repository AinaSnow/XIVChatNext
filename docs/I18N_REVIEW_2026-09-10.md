# 客户端国际化检查与修复（2026-09-10）

当前支持简体中文、英文及跟随系统。系统语言以中文开头时选择简体中文，其余回退英文。

## 已修复

- 连接、服务器管理、频道视图管理、通知、导出、密钥验证等旧窗口存在硬编码中文；保存的服务器列表按钮写死英文。改用资源绑定，已打开的控件和窗口标题随语言切换更新，关闭/卸载时解除事件订阅。
- 动态生成的频道、过滤分类、全选/取消全选按钮，以及历史频道筛选、发送频道菜单、通知频道标签未本地化。补齐对应资源；保留枚举值和已有配置。
- 主题选项原先直接显示 `System/Light/Dark`；改为对应语言名称。
- 断开连接和通信错误提示写死中文；改为资源文本。
- “本地存储的消息”实际控制视图内存缓存；改为“每个视图缓存的消息数”。旧协议回放数量改为“从旧版服务端请求的历史消息数”，与 SQLite 历史设置区分。
- 密钥验证原文要求比较“两个键”，但界面分别显示服务端和客户端公钥。现在明确核对服务端公钥与游戏插件中的服务端公钥，说明客户端公钥用途。
- 物品窗口的品级、装备等级、属性、魔晶石等界面标签和物品/地图默认标题接入资源；游戏传回的物品名、属性描述、地名、聊天内容保持原语言。
- 资源读取失败时改用调试输出，移除逐次枚举资源并向程序目录写诊断日志的行为。

## 验证

- `tests/LocalizationAudit.ps1`：中英文各 346 个键一致，无重复、空文本、格式参数差异；143 个静态引用全部存在。动态频道/过滤器资源另由 WinUI 测试验证。
- WinUI smoke：62 项检查通过。新增测试实际打开服务器和频道视图窗口，验证英文→中文→英文时标题、XAML 控件和动态选项刷新，同时保留未保存的服务器名称和频道勾选。
- 正常客户端重新构建成功，0 错误；仍有 3 条既有 Windows App SDK 发布配置警告。已打开正常入口版本。
- 物品 HTML 标签和地图默认标题通过资源审计与编译，本轮未用实时游戏物品逐项验证 WebView 显示。

## 范围与后续

- 本轮没有增加第三种语言，也不自动翻译聊天、游戏数据、用户自定义频道视图名称或既有历史消息。
- Windows 原生控件的系统菜单、日期选择器及第三方地图网页可能使用系统/网站语言。
- 主窗口里临时打开的内容对话框采用打开时的语言；其间切换语言需关闭后重开。已完成自动刷新的是本报告所列独立窗口及主要界面。
