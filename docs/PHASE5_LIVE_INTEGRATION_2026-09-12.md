# 第五阶段现场联调：装备快照第一步

2026-09-12，使用正常桌面客户端与游戏中的开发插件完成联调。角色为 Edelweiss Hare@Asura，魔兽使（ClassJob 43），等级 50，未处于等级同步。按照用户要求逐项推进，本次只完成当前装备读取、同件对比及头盔卸下／装回。

## 实机发现与修复

- 普通白钢角盔（Steel Sallet／スチールサレット，Item 2753）曾被判定为特殊装备。实际游戏表中 `ItemSpecialBonus=1` 的名称和条件为空，`EquipRestriction=1` 允许全部种族与性别；原先将非零关联均视为特殊的判定过严。现在排除普通默认项，同时继续保护实际特殊加成、受限装备及随机属性装备。
- 当前安装的 Lumina 类别表将魔兽使列命名为 `Unknown0`，而 ClassJob 43 的英文缩写为 `BST`，原先只查找同名属性会漏掉该职业。现在优先读取命名列；仅对已核对的 43／BST 组合兼容旧列，其他未知职业不推断。
- 等级／职业相关的主副属性修正（参数 55／56）明确按特殊装备处理，避免普通判定修正后将阿泽玛耳坠等可变属性饰品纳入静态差值计算。
- 表结构中的 `EquipRestriction` 实际关联种族类别，见 [EXDSchema Item](https://raw.githubusercontent.com/xivdev/EXDSchema/latest/Item.yml)；默认行与上述职业列的具体取值由本机游戏文件核对。
