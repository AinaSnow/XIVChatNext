# 第五阶段：游戏卡片、装备对比与收藏

物品卡片现在按需向插件查询详情、制作配方和可确认的获取来源；可打开材料、返回上一张卡片、查看来源地图、复制、收藏并返回聊天上下文。客户端与插件必须同时更新才能获取新增实时数据，旧端连接仍可显示原消息附带的内容。

## 数据与显示

- 游戏文件负责 ID、品质、基础属性、HQ 增量、装备要求、配方数量、商店关系及地图比例。中文名称、描述和属性标签从用户指定的 FFCafe XIVAPI 获取，以表名和行 ID 对应，使用 `language=chs`。中文数据单独缓存，不覆盖游戏数值；“游戏原文”可随时切回原始文本。
- 中文服务只提供最新合并数据，不支持版本固定或素材接口。缓存保留其实际响应版本、schema 和查询时间；文本缓存有效期七天，断网或无效/超大响应时保留已保存文本，最多 1,024 条文件，两路并发、256 KB 响应预算。地图中文文本同样独立于游戏地图参数。
- 配方显示制作职业、等级、星级、产量、材料与数量，以及可能的解锁要求。获取来源只列出能关联的金币商店、NPC、标示价格和采集区域；坐标不唯一或缺失时明确表示未知。未推断兑换、脚本商店、掉落、实时采集开放或角色解锁状态。
- 装备快照通过 `IGameInventory` 读取已装备容器，登录、职业/等级变化和库存事件触发刷新，游戏线程最多每 500 ms 检查一次。基础属性按参数 ID 对比；实际魔晶石单独列出，左右戒指分别选择。武器、特殊/自定义装备、不兼容部位、职业或等级限制会阻止差值评分；不计算同步、镶嵌上限或战斗收益。
- 每份装备快照带服务器来源、角色、登录批次、修订号和读取时间。断线/登出变为非实时，迟到或其他角色的回复不能重新激活旧快照。磁盘上的装备始终视为历史数据。

## 请求与缓存边界

- 新增客户端操作 12、服务器操作 16、能力字段 10 和客户端偏好 6；原字段/操作码不移动。
- 配方与来源每页最多 8 条，每个物品最多 2,048 条关联，响应上限 96 KB。每客户端最多 4 个未完成请求，全局最多 32 个，取出等待建立索引的请求仍计入额度；取消、超时或断开后释放。
- 后台读取捕获的静态 GameData/语言并建立索引，只在完成后发布；游戏文件/语言变化会取消旧代。装备实例读取留在游戏线程。客户端分页必须携带同一数据代，过期页不可混入新数据；切换卡片会取消旧请求并阻止迟到结果覆盖当前页面。
- SQLite v5 新增静态页、装备和收藏归属数据。静态页按服务器、游戏版本、语言、数据代、物品类型和页码隔离，最多 1,024 页；装备最多 128 份。迁移在事务内执行并事先备份。

## 收藏与来源

- 侧栏“收藏”提供已收藏与最近出现、当前角色与全部角色/服务器、名称或备注搜索、分组和标签筛选；已收藏项可编辑分组、标签和私人备注。
- “最近出现”按需从已有历史提取物品/地图链接，不复制聊天记录；一次扫描最多 100 条消息，一页最多增加 100 张卡片。单条消息有大量链接时，继续页会从该消息内的下一条链接恢复。
- 物品按 ID 与品质区分，地图按地图 ID 与坐标区分；收藏键包含原始服务器和角色，重复收藏可累积来源消息。无角色信息的旧消息保持未归属。
- 重新收藏/刷新快照不覆盖私人备注、分组、标签或已有关联。收藏消息不受普通历史保留期清理；取消收藏不会直接删除聊天。
- 来源跳转保留原始消息 ID、服务器与角色。打开历史上下文时关闭发送输入；即使切换了当前角色，也不会把来源消息归到新角色。

## 验证

- 通用回归：47 组，含畸形数据/请求预算、左右戒指、职业等级限制、数据库 v4→v5、归属保护、备注保留、离线与超大中文响应，以及原有十万条历史查询。
- 卡片 WinUI/WebView 流程：51 项检查通过，使用真实加密 TCP 连接和确定性中文接口夹具，覆盖渲染、品质、分页、材料返回、地图元数据、迟到响应、收藏/来源、中文原文切换、角色切换和离线快照。单条 250 链接消息用于验证最近卡片分页。
- 原有完整桌面流程：87 项检查通过，覆盖聊天虚拟化、好友/会话、历史与通知。
- 本机真实游戏文件：12 项检查通过；HQ 武器、装备职业/部位、不同游戏语言的职业限制、配方材料、采集区域、金币商店 NPC 与帧预算均由实际表读取。一次完整建立索引约 876 ms，主线程单次检查最多约 2.0 ms（本机结果）。
- 实际插件 DLL 的构造与登出保护检查：12 个注入服务通过，包括新增 `IGameInventory`；300 个清空世界行的模拟登出帧通过。
- 中英文各 481 个资源键一致；正常客户端和插件 Debug 构建通过。
- 生产中文字段查询复核：Item 37362 返回“加隆德工具套装”，响应版本为字符串 `2026071600010000`，与客户端解析和版本记录格式一致。

本轮没有在运行中的游戏里实际换装、镶嵌或跨职业核对快照；这些仍属于现场联调。静态文件检查与模拟装备回复不能替代该验证。
