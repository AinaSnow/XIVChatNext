# Brand assets / 品牌资源

## English

`logo-c1.png` is the selected master. The desktop uses a 256px PNG and multi-size ICO; the plugin uses a 512px icon. Run `Export-LogoResources.ps1` on Windows to regenerate exports without changing the design.

The public plugin catalog uses `XIVChatPlugin/Resources/icon.png`. Retired candidates, prompts and legacy artwork are in the local archive outside this repository.

## 简体中文

`logo-c1.png` 为当前品牌原图。客户端使用 256px PNG 和多尺寸 ICO，插件使用 512px 图标。在 Windows 运行 `Export-LogoResources.ps1` 可重新导出应用尺寸，不改变设计。

公开插件源使用 `XIVChatPlugin/Resources/icon.png`。旧候选、提示词和历史素材保留在仓库外本地归档。
